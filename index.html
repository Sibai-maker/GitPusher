连接你的 GitHub 账号

使用 Personal Access Token 授权，Token 仅保存在本机浏览器，不会上传到任何服务器。

如何获取 Token？需要哪些权限？
  1. 打开 GitHub → Settings → Developer settings → Personal access tokens
  2. Fine-grained token（推荐）：Repository permissions 勾选 Contents: Read and write、Metadata: Read-only、Administration: Read and write（用于新建仓库）；Account permissions 勾选 Administration: Read and write（用于新建仓库）。
  3. Classic token：勾选 repo（完整仓库读写，含私有库）与 workflow（如需修改 GitHub Actions 文件）。
